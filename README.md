# For Lasya

A little birthday magic in five chapters: an envelope to open, a cake with candles to blow out, a butterfly garden puzzle, an "I love you" reveal, and a letter.

Live page: https://gireeshkumarreddy.github.io/Lasya/

## The puzzle

Four butterflies carry clues. Catch them all and the nine gift boxes unlock; only one box holds the secret. Wrong boxes give a cute hint, and the hints get stronger with each wrong guess.

## Changing the words

Everything lives in `index.html`. The letter, the signature, and the reply message are in the `CONFIG` block near the top of the script. The name also appears in a few headings, so search for "Lasya" to change it everywhere.
